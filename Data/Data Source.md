## Data

This project uses two publicly available fraud detection datasets sourced from Kaggle.

### Credit Card Fraud Detection

**Kaggle dataset:** [mlg-ulb/creditcardfraud](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud?resource=download)

**Direct import (Kaggle Hub):**
```python
# Download latest version
path = kagglehub.dataset_download("mlg-ulb/creditcardfraud")
print("Path to dataset files:", path)
```
